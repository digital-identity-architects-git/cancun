# Cancún Itineraries — Semantic Content Strategy

> **Goal:** Own the "Cancún itinerary / trip planning" niche through topical authority.
> **Domain:** cancunitineraries.com
> **Edge:** First-hand experience (we're relocating to Cancún) + original photography on every page.
> **Method:** Pillar-and-cluster architecture. Each cluster has one broad pillar page that links down to deep, specific cluster posts; cluster posts link back up and sideways. This is what builds *semantic topical authority* — Google sees the site comprehensively covers the entity "Cancún travel."

---

## Why this works (the strategy in one minute)

1. **Itineraries are the brand and the money page.** The domain promises itineraries, so the itinerary cluster is the hub everything links into. Every other cluster (beaches, food, ruins) exists to feed the itinerary pages with internal links and answer the sub-questions a planner asks.
2. **Experience beats volume.** The web is drowning in AI-generated "Top 10 Cancún" listicles. Our moat is *we live there*: real photos, real prices we paid, real bus routes we rode, real mistakes. Every page should carry a first-person, dated, photographed detail no competitor can fake. This directly satisfies Google's E-E-A-T (Experience) signal.
3. **Cover the full intent funnel.** Dreaming ("is Cancún worth it") → Planning ("7 day Cancún itinerary") → Booking ("best area to stay") → In-trip ("how to get from CUN to hotel zone") → Living ("moving to Cancún"). Owning all five stages = owning the traveler.
4. **Photography = compounding asset.** Every original photo we shoot is a unique image-search entry point, a social asset, and a trust signal. Shoot wide: signage, menus, bus interiors, sunrise/sunset, crowds vs. empty, rainy days — the unglamorous shots competitors never have.

## Internal linking rules (the "semantic" part)

- **Every cluster post links *up* to its pillar** and the pillar links *down* to every post. This is the cluster's "topical mesh."
- **Every itinerary page links *out* to the specific cluster posts it references** (e.g., the 7-day itinerary mentions Chichén Itzá → links to #29, mentions a cenote → links to #45). The itinerary hub becomes the spider in the web.
- **Use descriptive anchor text** (the target keyword), never "click here."
- **3–6 internal links per page minimum.** Orphan pages get no authority.
- Add **breadcrumb navigation** (`Home › Day Trips › Chichén Itzá`) for both UX and structured-data benefit.

## On-page SEO checklist (apply to all 100)

- [ ] One `<h1>` containing the primary keyword; logical `<h2>`/`<h3>` outline.
- [ ] Title tag ≤ 60 chars, meta description ≤ 155 chars, both keyword-led (the existing pages already do this well — keep the pattern).
- [ ] **Original photos** with descriptive, keyword-aware `alt` text and real filenames (`playa-delfines-sunrise.webp`, not `IMG_4821.webp`).
- [ ] WebP, lazy-loaded, explicit `width`/`height` (matches current site convention).
- [ ] FAQ block at the bottom → eligible for FAQ rich results and "People Also Ask."
- [ ] **Structured data**: `Article` + `BreadcrumbList` everywhere; `FAQPage` on FAQ blocks; `TouristAttraction`/`TouristTrip` on itinerary and attraction pages.
- [ ] A dated, first-person "we were here" note + photo on every page (the experience signal).
- [ ] Add each new URL to `sitemap.xml`.
